# 照某個家族的風格畫像素貼圖

這份是**通用的方法**。某個家族的具體規矩（顏色、外框亮度、標準形、視角、機器面怎麼畫）寫在 `profiles/<家族>/profile.md`。

| 要做的事 | 讀哪裡 |
|---|---|
| 家族還沒有檔案 | [references/learn-a-style.md](references/learn-a-style.md)：怎麼量一個家族、寫出檔案 |
| 家族已有檔案 | `profiles/<家族>/profile.md`（目前有 `ae2`） |
| 家族裡沒有的一般物品（工具、零件、機件、容器） | [references/general-items.md](references/general-items.md) |
| 方塊、模型、不是純貼圖的東西 | [references/models.md](references/models.md) |
| 排色階 | [references/ramps.md](references/ramps.md) |

`examples/key.svg`＋`key.px` 是「SVG 構造 → 轉像素 → 補色」的完整範例（一把斜放的鑰匙）。

## 第 0 步：確定是哪個家族

- 問清楚要像誰：一個模組、一組模組（例如 AE2 和它的附屬）、還是原版。答案就是參考 jar 的清單。
- 只以那個家族的原圖為師。**使用者專案裡自己的貼圖不是範本**，除非使用者明說要沿用。
- `profiles/` 裡有就讀；沒有就照 learn-a-style.md 量一次，寫好 `profiles/<家族>/profile.md`，給使用者看過再開始畫。

## 順序

**認得出 ＞ 形準確 ＞ 風格。** 先讓東西看得出是什麼，再把形修準，最後才套家族的上色。風格規則和辨識度衝突時，留辨識度。

預設從零畫。整張改色只用在等級變體、同一物件的顏色版本、發光層，或使用者明說要沿用某張原圖時。

## 流程

1. **看**。`unpack_refs.py` 解包家族的 jar，`sheet.py` 把和題目最近的幾十張原圖排成一張來看。每次都看，不憑記憶。
2. **定形**（見〈形〉）。判斷題目是哪一類，先畫一張**純色剪影**。剪影認不出來就改形，不往下畫。
3. **定色階**。照家族檔案的顏色規矩自己排；沒有就照 ramps.md 的走法。
4. **畫**。先在 SVG 裡把每個零件、每個面畫成形狀，`svgpx.py` 轉成像素，再手動補色。簡單的東西也可以直接寫字元格子給 `px.py`。
5. **檢查**（見〈檢查〉）。
6. **混排**。和二三十張原圖混在一張圖裡看。
7. **遮名測試**。交給不知道題目的人說每一格是什麼。
8. **交給使用者**。附放大圖，照實說哪裡拿不準。

## 形

先判斷題目是哪一類。

### 家族裡已有的東西：照標準形

很多家族的同一類東西（粉、錠、卡片、晶簇、材料方塊）共用同一個輪廓和稜線位置，錯一格就看得出來。`canon.py 關鍵字 --refs 家族資料夾` 會列出共用的輪廓與明暗骨架。照它的輪廓一格不動，只換色階。

### 板與塊：家族的立體視角

錠、匣、晶片這類方塊狀的立體零件，家族通常有固定的視角（例如 AE2 是轉約 30 度、內傾約 60 度：長邊每 3 格升 1 格、深度邊 1:1、看得到頂面）。視角寫在家族檔案裡；`iso.py` 用那個斜率把方盒投影成字元骨架。

### 一般物品與機件：照 general-items.md

家族裡沒有的東西（磁鐵、鑰匙、電池、馬達、幫浦、閥門、燈泡、齒輪、工具）：

- 拆成兩到三個分開的零件，每個零件一種材質、一個明度，零件之間有清楚的分界。
- **3/4 的角度，不是沿某一軸的平視**：每個零件看得到兩三個面，讀得出是圓柱、方塊、圓盤還是錐。
- 擺法：有腳的零件、電池、瓶罐、燈直立；手持工具沿對角線；有軸或缸體的機器橫放；圓盤畫圓；齒輪、風扇正面。
- 粗：零件至少 3 格厚，整體沿主軸佔 13–15 格。
- 功能零件伸出輪廓：腳、軸、法蘭、極頭、齒。
- 兩端不要一樣（會像糖果）；錐形要真的收窄到 1–2 格。
- 現實裡是一種材質的東西（鑰匙、扳手、齒輪）整支一種顏色；兩種材質時，主色給最大的零件。

### 方塊：先決定造型

不要預設成立方體。先讀 models.md 決定造型。

### SVG 畫法的規矩

- 每個面一個形狀；斜放的東西用旋轉，等寬的零件就不會畫成三角形。正方形旋轉 45 度會變菱形（像寶石），要斜放的頭做成橫跨方向較長的長方形。
- 轉完一定看像素格子，不是看向量：孔、窗、凹槽要在格子裡置中（四邊留一樣多的材質），環要整圈閉合（孔和外框之間至少隔一格材質）。
- 孔的唇四邊用同一個明度；一邊暗一邊亮會讓距離看起來不一樣。
- 細的零件轉像素時容易被吃掉或和旁邊融在一起，畫長一點、或轉完手補。

### 共通的規矩

- **不要多伸出一格**：零件在輪廓邊緣多一格、低一格，是一眼看出 AI 畫的瑕疵。被擋住中段的東西，兩端要在同一條線上、露出一樣長。
- **不要加家族沒有的小東西**：面上點綴的孔、點、燈、螺絲、鉚釘、鏽、木紋——除非在家族原圖裡真的看過。
- 物品佔畫布 12–14 格，四周留 1 格透明，除非家族的標準形碰邊。

## 上色

家族怎麼上色寫在家族檔案。下面幾條在量過的家族（AE2、格雷）都成立，沒有檔案時當預設：

- **明暗跟著面走**：方塊的頂面、正面、側面各一個明度，交界是硬轉折；圓柱的亮暗沿著軸排成直條；不是整個零件從左上到右下一條漸層。
- **不要每格降一階的平滑漸層**。面先鋪一個底色，再用 1 格寬的短筆劃畫亮邊、暗邊、溝和高光，明暗靠跳兩階。
- 落點在三種壞樣子中間：漸層（每格都不同、滑過去）、塑料（整片平塗加長直線）、雜點（每格都不同色）。
- 外框封閉、整圈暗色；外框的亮度與顏色數照家族量到的。
- 使用者有紅綠色盲時，要分辨的兩個顏色選明度和冷暖都分得開的（橘配藍），不要紅配綠。

## 檢查

工具給的是提示，數字是拿家族自己的分布來比。**不要為了讓數字好看去改形與明暗**，也不要把自己量出來的差異當成使用者的意思。

- `outline.py 家族資料夾 檔案…`：外框夠不夠暗、夠不夠封閉。
- `analyze.py --family 家族資料夾 檔案…`：上色的結構（漸層佔比、筆劃、色塊、單點），`--maps` 畫成對照圖。
- `spectrum.py`、`tells.py`、`edge.py`：只當提示。

**遮名測試**：`sheet.py … --no-labels` 排好，交給不知道題目的人（使用者，或一個沒看過題目的代理），問「這是什麼？叫不出名字的話，它由哪些零件組成？」自己看不算。

- 有公認符號的東西（磁鐵、鑰匙、扳手、電池、齒輪、燈泡）要叫得出名字。
- 機件（幫浦、馬達、活塞）叫不出名字沒關係，但要說得出構造。被說成一團、石頭、蛋就是不及格。

## 和使用者來回時

- 最終裁判是使用者的眼睛。拿不準的地方照實說。
- 使用者指出「哪一塊、往哪移幾格」時照做，不另外推理別的原因。
- 一句評語有兩種讀法時，先問是哪一種，或把自己的讀法講明再動手。
- 使用者沒說原因時，不要自己從統計推一條規則寫進來。
- 新的一版用眼睛看比較差就退回上一版。
- 使用者糾正之後：改家族檔案（或這份）裡那一句方法，經過記在 `profiles/<家族>/history.md`，不要把故事堆進方法裡。

## 工具

都在這個 skill 的 `scripts/`（下面寫 `S/`）。需要 Python 3 與 Pillow；在 Windows 上先設 `PYTHONIOENCODING=utf-8`。預設的解包資料夾是系統暫存區的 `style_refs/`，每個家族用自己的子資料夾，其他工具用 `--refs` 或第一個參數指過去。

| 工具 | 用途 |
|---|---|
| `python S/unpack_refs.py 輸出資料夾 [--ref 資料夾] [--jars 路徑或萬用字元…] [--only 命名空間…]` | 解包 jar 的貼圖、模型、方塊狀態。 |
| `python S/profile.py 家族資料夾 [--kind item\|block] [--out 檔.md]` | 量一個家族：顏色數、亮度、外框、相鄰階差、上色結構、最常用的顏色。寫家族檔案的起點。 |
| `python S/sheet.py OUT.png 路徑… [--match 字串] [--max N] [--scale N] [--cols N] [--shuffle 種子] [--actual] [--no-labels]` | 把資料夾或檔案排成放大圖；混排自己的圖時逐檔列出。 |
| `python S/dump.py 檔案…` | 把圖印成字元格子＋色表，用來看某個畫法，不是用來抄。 |
| `python S/svgpx.py IN.svg 輸出前綴 [--ss 12] [--min 0.35]` | SVG 轉 16×16：每格取面積最大的形狀的顏色，不混色；`data-edge` 指定外框色，`fill="clear"` 挖洞；同時輸出可手改的 `.px`。 |
| `python S/px.py 檔案.px [輸出資料夾]` | 字元格子轉 PNG；調色盤分大小寫。 |
| `python S/canon.py 關鍵字 --refs 家族資料夾 [--not 字…] [--kind item\|block]` | 找某類東西的共用輪廓與明暗骨架。 |
| `python S/iso.py "長 高 深" [...] [--unit 像素] [--slope 3\|2]` | 把方盒投影成「長邊 slope:1、深度邊 1:1、看得到頂面」的字元骨架。 |
| `python S/outline.py 家族資料夾 檔案…` | 輪廓的暗度與封閉度，對照家族分布。 |
| `python S/analyze.py [--family 家族資料夾] 檔案…` | 上色結構；`--maps OUT.png 檔案…` 畫成對照圖。 |
| `python S/model_render.py OUT.png 模型… [--refs 家族資料夾] [--tex 資料夾] [--yaw 45 225] [--boxes]` | 方塊模型的等角渲染。 |
| `python S/blocks.py 檔案… [--refs 家族資料夾] [--family]` | 一個方塊面有幾個大色塊。 |
| `python S/spectrum.py`、`S/tells.py`、`S/edge.py` | 頻譜與像素統計的提示；`tells.py` 的門檻是 AE2 量的。 |
