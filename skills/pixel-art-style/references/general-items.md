# 一般物品怎麼畫得「能看」

風格之前的事：先讓人看得出是什麼。這份是看了格雷科技（GregTech，gtceu）約 500 張物品圖之後歸納的構造法，對任何家族都適用。**學的是構造與擺法，不是格雷的顏色與質感**；顏色、外框、上色照目標家族的檔案。

要看格雷原圖：`unpack_refs.py <temp>/style_refs/gtceu --jars ".../mods/gtceu-*.jar" --only gtceu`。用 AE2 上色畫的成品看 `profiles/ae2/examples/items_general.px`，斜放工具的 SVG 範例是 `examples/key.svg`。

## 及格的標準

- **有公認符號的東西**（磁鐵、鑰匙、扳手、電池、齒輪、燈泡、提燈）：遮名後要叫得出名字。
- **機件**（幫浦、馬達、電容、活塞、閥門、噴嘴、發射器）：叫不出名字沒關係，但要說得出構造——「一個圓桶，兩端各一個法蘭」「一個罐子，下面兩根腳」。被說成一團、一塊石頭、一顆蛋就是不及格。連格雷自己的幫浦，遮名後也只被說成「兩端有金屬接頭的袋子」；機件靠名字與整組的一致性辨認。

## 構造法

1. **拆成兩到三個分開的零件，每個零件一種材質、一個明度**，零件之間用深色的縫或外框隔開，不要融成一片。
2. **用最好認的那個側面**：
   - 有接腳的電子零件、電池、瓶罐、燈：正面直立，腳或底在下。
   - 手持的工具與細長的單件（鑰匙、鎚子、鑽頭、扳手、桿、線圈）：沿對角線，左下到右上。
   - 有軸、有缸體的機器（馬達、幫浦、活塞）：水平側視，軸或桿往一邊伸出去。三個零件排成一列在 45 度上放不下。
   - 圓盤（透鏡、硬幣、晶圓）：正圓。
   - 扁平會轉的東西（齒輪、風扇）：正面，用光打破對稱（上與左亮、下與右暗）。
   - 家族的板與塊視角（例如 AE2 的轉 30 度、內傾 60 度）只留給錠、元件、晶片、匣這類方塊狀的零件。
   - 不論哪種擺法，都是 3/4 的角度：每個零件看得到兩三個面，不是沿某一軸的平視剪影。
3. **粗**。零件至少 3 格厚，桶身 6 格以上，整體沿主軸佔 13–15 格。1 格寬的只有腳、線、軸尖。
4. **功能零件伸出輪廓**：腳、軸、法蘭、極頭、齒、噴口。它們改變剪影，比表面上任何細節都有用。
5. **現實裡是一種材質的東西就只用一種顏色**（使用者：「鑰匙不會有兩種顏色」）。鑰匙、扳手、齒輪、鎚頭都是一整塊金屬，整支用同一條色階，不要為了好看把頭和桿分成兩色；AE2 的石英扳手、地獄石英扳手也都是單色。只有現實裡本來就由兩種材質組成的東西（木柄的鎚子、磁鐵的極頭、燈泡的玻璃與燈頭）才分色。
6. **兩種材質時，主色給最大的那個零件**（罐身、桶身、U 形、玻璃裡的光與火），金屬配件才用中性色。反過來把主體畫成灰的、只留一小塊彩色，東西會變成一個灰盒子（提燈變成掛鎖、風扇的葉片變成灰片）。
6. **錐形要真的收窄**：從 5–6 格收到 1–2 格。粗細一樣就只是一根桿。
7. **兩端不要一樣**：桶身兩端各一個相同的法蘭就是包裝糖。一端大法蘭、另一端細軸，或側面加一個出口。
8. **不要加小特徵**：面上不點綴孔、點、燈、指示環。
9. **斜放的頭要夠大夠方**。鎚頭、鑽頭的工作端至少 5×5，而且留著明顯的直角或螺紋階梯；3×3 的圓頭插在棍子上會被看成魔杖，沒有螺紋的斜錐會被看成劍。斜的階梯手畫，不要用程式算 45 度（會出現棋盤格）。

## 試過的構造

| 東西 | 構造 | 遮名後 |
|---|---|---|
| 電容 | 直立罐子＋中間一條色帶＋兩根腳 | 短腳上的罐子，電容或電池 |
| 電池 | 直立圓柱＋頂端小凸點＋上下兩圈色帶 | 電池 |
| 燈泡 | 圓泡（看得到燈絲）＋螺紋燈頭 | 燈泡 |
| 齒輪 | 正面八齒＋中心的軸 | 齒輪 |
| 磁鐵 | 直立 U 形＋兩個極頭一淺一深 | 馬蹄磁鐵 |
| 馬達 | 灰機殼開一個窗露出直條線圈＋右邊伸出軸＋兩隻腳 | 電動馬達 |
| 閥門 | 橫管＋兩端法蘭＋中央立桿＋頂上一條手輪 | 帶手輪的管閥 |
| 幫浦 | 水平：左大法蘭＋有肋的桶身＋右細軸＋上方帶法蘭的出口管 | 帶管的橫式流體槽 |
| 噴嘴 | 直立：螺紋接頭＋六角法蘭＋收到 2 格的錐 | 漏斗或錐形噴嘴 |
| 提燈 | 提環＋蓋＋深色框裡的玻璃與火焰＋底座 | 提燈 |
| 鑰匙 | 圓環頭＋帶齒的斜桿 | 鑰匙 |
| 鎚子（失敗） | 斜放，鎚頭太小太圓 | 頂端有寶石的魔杖 |
| 鑽頭（失敗） | 斜錐，沒有螺紋階梯 | 劍 |
