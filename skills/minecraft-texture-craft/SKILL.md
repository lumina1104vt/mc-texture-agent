# 畫 16×16 Minecraft 貼圖的規矩

順序：**認得出 ＞ 形準確 ＞ 風格**。先讓人一眼看出是什麼，再修形，最後才調色與細節。規則和辨識度衝突時，留辨識度。

## 色票與亮度

- 每張 6–32 色，最多不超過 48 色；超過就是漸層或抗鋸齒，不是像素風。
- 前五大色塊要佔不透明像素的七成以上；顏色散成雜點就是失敗。
- 亮度要有層次：最亮和最暗的差距（P90−P10）約 0.35–0.75；中間調要有足夠的格數，不要只剩接近黑和接近白。
- 暗色仍要有一點彩度（紅的暗部偏酒紅、綠的暗部偏深藍綠），不要變成死灰或純黑；最亮的一階是帶一點色的白。

## 明暗與表面

- 光從上方來，略偏左：上面比下面亮，亮邊在上和左，暗邊在下和右（`bevel` 就是這個方向）。
- 明暗跟著面走：不要整個零件從左上到右下一條漸層。
- 表面先鋪一個底色，再加 2–4 個相近的色階（相差約 15–25），用 1 格寬的短筆劃畫亮邊、暗邊、溝和高光。明暗靠跳兩階，不要每格降一階。
- 要落在三種壞樣子的中間：漸層（每格都不同、滑過去）、塑料（整片單色加長直線）、雜點（每格不同色，像電視雜訊）。
- 自己排色階：從「一看就是這個材質」的中間色出發。往暗走四五階，色相往藍紫轉一點、亮度逐階降；往亮走四五階，色相往鄰近的暖色滑一點。明度不要等距：暗端兩三階擠在一起（陰影、縫），中段跳得大（面與面的交界），亮端再擠在一起（高光）。總共 8–11 階，方塊面通常只取其中三到五階。

## 方塊的面

- 左右兩邊（x=0 與 x=15）的亮度要接近，相鄰的面接起來才不會出現一亮一暗的縫；橫向的帶狀結構要連續穿過整個面。
- 窗、凹槽、標記放在框內，最多 1–2 個重點色，數量要少。
- 底面要簡單（一圈邊加平整的凹板）；高頻的交叉細線縮小後會變成雜訊。

## 礦石與嵌入礦物的方塊

- 礦石 = 整張不透明的底材 + 蓋在上面的礦物簇。永遠先用 `new_canvas(底材色)` 把整張鋪滿，再蓋礦物；不要把底色留成透明或黑色。
- 底材用該方塊底材的顏色（石頭是中性灰），3–4 個相近的色階，零星撒深淺的點，不要整片單色。
- 礦物簇：3–6 簇，大小不同（2–4 格），不要碰到邊，彼此分散。每簇 3–4 色：暗邊、本體、亮面、一格高光。
- 參考圖如果大部分格子是透明的（`.`），那只是疊在底材上的礦物圖案，不含底色，底色要自己鋪。
- 純色方塊（泥土、石頭、木板）：一個底色加少量深淺雜紋，同一色相。
- 玻璃、樹葉這類本來就透明的方塊是例外：透明的地方保持 alpha 0，其餘不透明。

## 一般物品（工具、零件、機件、容器）

1. 拆成兩到三個分開的零件，每個零件一種材質、一個明度，零件之間用較暗的縫隔開。
2. 擺法：電池、瓶罐、燈、有腳的零件直立；手持工具和細長的單件沿對角線（左下到右上）；有軸的機器水平側視；圓盤畫成正圓；齒輪、風扇畫正面，用光打破對稱。都用 3/4 的角度，每個零件看得到兩三個面。
3. 要粗：零件至少 3 格厚，整體沿主軸佔 13–15 格，1 格寬只留給腳、線、軸尖。物品整體佔 12–14 格，四周留 1 格透明。
4. 功能零件要伸出輪廓：腳、軸、法蘭、極頭、齒、噴口。
5. 現實中是一種材質的東西（鑰匙、扳手、齒輪、鎚頭）整件用一種顏色；本來就由兩種材質組成的才分色（木柄的鎚子、磁鐵的極頭、燈泡的玻璃和燈頭）。
6. 兩種材質時，主色給最大的零件，金屬配件才用中性色；不要把主體畫成灰的、只留一小塊彩色。
7. 錐形要真的收窄（5–6 格收到 1–2 格）；兩端不要一樣，否則像包裝糖。
8. 斜放的頭要夠大夠方：鎚頭、鑽頭的工作端至少 5×5，保留直角或螺紋階梯。斜的階梯用 `set_pixel` 或字元格子手畫，不要用公式算 45 度（會出現棋盤格）。
9. 辨識標準：磁鐵、鑰匙、扳手、電池、齒輪、燈泡要一眼叫得出名字；機件（幫浦、馬達、活塞）至少要看得出構造，不能像一團或一顆蛋。

試過的構造：

| 東西 | 構造 |
|---|---|
| 電池 | 直立圓柱，頂端一個小凸點，上下各一圈色帶 |
| 燈泡 | 圓泡（看得到燈絲）加螺紋燈頭 |
| 齒輪 | 正面八齒，中心一個軸 |
| 磁鐵 | 直立 U 形，兩個極頭一淺一深 |
| 鑰匙 | 圓環頭加帶齒的斜桿 |
| 幫浦 | 水平：左大法蘭、有肋的桶身、右細軸、上方帶法蘭的出口管 |

## 要避免的

- 亮度只剩極端：全黑全白，中間調空掉。
- 左右邊一亮一暗，相鄰的面接縫突兀。
- 電視雜訊（逐格隨機抖動）或整片單色塑料。
- 零件在輪廓邊緣多伸出或少一格；被擋住中段的東西，兩端要在同一條線上、露出一樣長。
- 加沒必要的小東西：面上點綴的孔、點、燈、螺絲、鉚釘、鏽、木紋。
- 底面的高頻交叉線。
